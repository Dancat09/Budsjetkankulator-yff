Budsjettkalkulator 
Jeg har laget en enkel budsjettkalkulator med HTML, CSS og JavaScript. 
Brukeren kan legge til inntekter og utgifter, velge kategori og se månedlig saldo. 
Budsjettet lagres med localStorage, slik at det fortsatt er der når siden åpnes igjen. Det er også mulig å skrive ut budsjettet.
Jeg har brukt Git underveis for å lagre forskjellige versjoner av prosjektet.
Jeg har brukt mye informasjon og eksempler fra W3Schools for å lære og løse problemer underveis.

Utfordringer
En utfordring var å få JavaScript til å regne ut saldoen riktig og få inntekter og utgifter til å vises på siden. 
Jeg hadde også litt problemer med localStorage og brukte W3Schools for å finne eksempler og forstå hvordan det fungerte.
